# Sprint 08 — Explainable local AI planning V0.5
Base 3761913b360f34c93a2712f820252ef362b3b888 (V0.4 RC1; CI success).
Pure planner planAgentDecision exposes goal, reason, actual next intent, advisory steps, task/peer IDs and bounded memory evidence. LocalBrain executes the next intent via existing simulation and writes only the proposed memory. Recall filters by agent, topic/peer, past seven simulated days, and ranks by importance and recency. Contextual blocked-work and follow-up dialogue; no automatic unblocking, financial mutations or skill awards. No LLM, external API, dependencies or save schema changes. Steps are advisory, not a persistent multi-step execution queue. UI should label preview vs actual state; do not call decideNextIntent for display because it writes memory. Existing 20-agent roster remains fixed. New tests authored; CI pending.
