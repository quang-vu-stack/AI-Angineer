# AI Engineer Academy — Zero to Advanced

Website học AI Engineer từ con số 0 đến nâng cao bằng tiếng Việt.

## Nội dung
- 12 giai đoạn, 83 bài học, 12 dự án.
- Bài tập Python, trắc nghiệm, ghi chú và theo dõi tiến độ.
- Trang web tĩnh `index.html` — không cần Node.js.
- Python Playground cần Internet để tải Pyodide.
- Tiến độ lưu trên trình duyệt, chưa đồng bộ giữa các thiết bị. Hãy xuất bản sao lưu JSON định kỳ.

## Xuất bản trên GitHub Pages

Repository: https://github.com/quang-vu-stack/AI-Angineer

1. Nếu dùng GitHub Free, chuyển kho **Private → Public** trong **Settings → General → Danger Zone → Change repository visibility**. Việc này công khai mã nguồn.
2. Vào https://github.com/quang-vu-stack/AI-Angineer/settings/pages
3. **Build and deployment → Source: Deploy from a branch**.
4. Chọn **main / (root)** và nhấn **Save**.
5. Sau khi GitHub xác nhận xuất bản, mở https://quang-vu-stack.github.io/AI-Angineer/

GitHub Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
