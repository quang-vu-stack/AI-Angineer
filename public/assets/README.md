# Public Assets Directory (V0.1)

V0.1 sử dụng hình học procedural tối ưu (`InstancedMesh` + low-poly avatars) để đảm bảo chạy 0-cost, tải tức thì và đạt mục tiêu 60 FPS trên trình duyệt Windows.

Cấu trúc sẵn sàng cho V0.2+ khi nạp mô hình GLB/GLTF:
- `public/assets/models/furniture/`
- `public/assets/models/characters/`
- `public/assets/textures/`
